## 🎧 What is NUViA?

NUViA is an Android music player designed to make listening feel less like operating a utility and more like living inside the music.

The app combines a full playback stack with a visual system built around:

- 🧊 Translucent Liquid Glass surfaces
- 🌈 Artwork-driven atmosphere
- 🎵 Full music playback controls
- 🔎 Music discovery and search
- 📚 Local library management
- 🎤 Lyrics
- ⬇️ Downloads and offline playback
- 🧠 Smart audio analysis
- 🎨 Personalization
- 📱 Minimal Mode
- 💾 Backup and restore
- ⚙️ Developer and diagnostic tooling

The goal is simple:

> **Your music. Your atmosphere. Your way.**

## 🖼️ The NUViA Experience

NUViA is designed around the idea that the interface should adapt to the music instead of forcing the music into a static interface.

## 🧱 Architecture

NUViA is an Android application built with **Kotlin**, **Jetpack Compose**, **Gradle**, and native audio-analysis components.

### Core structure

```text
NUViA
├── Android / Kotlin
├── Jetpack Compose UI
├── ViewModel-based app logic
├── Media3 playback stack
├── Playback Service
├── Player Connection
├── Download Service
├── Audio / metadata processing
├── Lyrics system
├── Smart audio analysis
├── Native C/C++ analysis
└── Liquid Glass design system
```

## 🧠 Smart Audio Engine

NUViA includes native audio-analysis infrastructure for extracting useful information from tracks.

The analysis layer contains components for areas such as:

- 🥁 Tempo / beat analysis
- 🌊 Mel-spectrogram generation
- 🎙️ Vocal-oriented analysis
- 🎼 Track feature extraction
- 🔬 Native audio processing
- 🧠 Smart analysis orchestration

Native components are built separately from the Kotlin UI layer and exposed through the app's analysis interfaces.

## 📲 Build NUViA

### Requirements

You will need:

- Android Studio
- JDK compatible with the project
- Android SDK
- Android NDK where required by the native analysis components
- Git
- A connected Android device or emulator

### Clone

```bash
git clone https://github.com/aadhil06dev/Nuvia-Musics.git
cd Nuvia-Musics
```

### Debug build

```powershell
.\gradlew.bat assembleDebug
```

### Install debug build

```powershell
.\gradlew.bat installDebug
```

### Release build

A release build requires a local signing configuration.

Create:

```text
keystore.properties
```

using the structure in:

```text
keystore.properties.example
```

Then:

```powershell
.\gradlew.bat assembleRelease
```

> 🔐 Never commit your private keystore or `keystore.properties`.

---

## 🔐 Release Signing

NUViA releases are signed builds.

The repository intentionally keeps private signing credentials outside Git.

The release configuration expects:

```properties
storeFile=nuvia-release.jks
storePassword=
keyAlias=nuvia
keyPassword=
```

Keep the real values private.

### Important

The release keystore is part of the app's long-term update identity.

**Back it up securely.**

Losing the signing key can prevent future releases from being installed as updates over an existing installation.
